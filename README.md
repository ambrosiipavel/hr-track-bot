# HR-бот: мини-CRM для рекрутинга в Telegram

Внутренний бот для ведения кандидатов: рекрутер заводит кандидата, координатор
ведёт его по статусам, администратор видит всю картину. Отдельная веб-панель
не нужна — вся работа происходит в Telegram.

## Роли

| Роль | Что может |
|---|---|
| Рекрутер | Добавляет кандидата, назначает координатора |
| Координатор | Видит **только своих** кандидатов, меняет статус |
| Администратор | Видит всех кандидатов, статистику, управляет сотрудниками |

## Статусы кандидата

`Новый` → `Связались` · `Не удалось связаться` · `Перезвонить` · `В процессе`
→ финальные: `Вышел на работу` или `Отказ`

Закрыть кандидата можно только финальным статусом. При отказе бот
обязательно запрашивает причину — без неё статус не сохранится.
Каждое изменение пишется в историю: кто, когда, с какого на какой статус.

## Стек

- Python 3.12, aiogram 3
- SQLAlchemy 2 (async), SQLite
- APScheduler — напоминания
- openpyxl — выгрузка в Excel

Переход на PostgreSQL — замена одной строки `DATABASE_URL` в `config.py`.

## Возможности

**Рекрутер** — добавляет кандидата пошагово, с проверкой формата телефона,
и назначает координатора. Координатор получает уведомление сразу.

**Координатор** — видит список своих открытых кандидатов, меняет статус.
При отказе бот требует причину, при статусе «перезвонить» — количество дней,
после чего ставит напоминание. По каждому кандидату доступна полная история.

**Администратор** — добавляет и отключает сотрудников прямо в боте,
смотрит статистику по статусам и список зависших кандидатов,
ищет по базе командой `/find` и выгружает всё в Excel командой `/export`.

**Напоминания** — ежедневно в 10:00 координатор получает список тех,
кому сегодня перезвонить, и отдельно тех, кто висит без результата
дольше трёх дней.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | вход, определение роли |
| `/cancel` | всем | прервать текущий ввод |
| `/adduser` | админу | добавить сотрудника |
| `/find текст` | админу, рекрутеру | поиск по ФИО, телефону, должности |
| `/export` | админу | выгрузка в Excel |

## Структура

```
├── bot.py              точка входа
├── config.py           настройки из .env
├── filters.py          проверка доступа по ролям
├── keyboards.py        клавиатуры
├── database/
│   ├── models.py       таблицы
│   └── db.py           запросы
├── handlers/
│   ├── common.py       /start, отмена
│   ├── recruiter.py    добавление кандидата
│   ├── coordinator.py  статусы, история
│   └── admin.py        сотрудники, статистика, поиск, экспорт
└── services/
    ├── reminders.py    задачи по расписанию
    └── export.py       выгрузка в Excel
```

## Запуск

```bash
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env         # вписать токен и свой Telegram ID
python bot.py
```

При первом запуске создаются таблицы, а пользователь из `ADMIN_ID`
автоматически заводится администратором.

## Безопасность

- Токен хранится в `.env`, файл исключён из репозитория
- Пользователи, которых нет в таблице `users`, не обслуживаются вовсе
- Координатор не может открыть или изменить чужого кандидата — проверка
  выполняется на сервере, а не скрытием кнопок
